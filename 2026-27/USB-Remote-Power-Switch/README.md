# Rover USB 3.0 Remote Power Switch

USB 3.0 Type-A male-to-female pass-through PCB
with GPIO-controlled VBUS power switching.

## Requirements
- USB 3.0 (5 Gbps)
- USB-A male input and female output
- 500-900 mA target load current
- 3.3V / 5V GPIO control
- HIGH = Power OFF
- LOW or floating = Power ON

## Status
Work in progress — schematic and PCB under development.
